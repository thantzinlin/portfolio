# Personal Portfolio Website

This is a personal portfolio website built with React, Vite, Tailwind CSS, and Framer Motion.

## Features

- **React (latest version)**
- **Vite** as the build tool
- **Tailwind CSS** for styling
- **React Router** for navigation
- **Framer Motion** for animations
- **Responsive design** (mobile, tablet, desktop)
- **Dark mode** toggle (saved in `localStorage`)
- **Reusable components**
- **SEO-friendly meta tags**
- **Accessible UI (ARIA labels)**
- **Smooth page transitions**
- **Scroll-to-top on route change**

## Pages

- **Home**: Hero section with name, title, short intro, and call-to-action buttons.
- **About**: Profile section, skills list, and experience timeline.
- **Projects**: Project cards with image, title, tech stack, short description, and links.
- **Contact**: Contact form and social media links.
- **Not Found**: 404 page.

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

### Development

To start the development server, run:

```bash
npm run dev
# or
yarn dev
```

The server will start on `http://localhost:5173`.

### Build

To create a production build, run:

```bash
npm run build
# or
yarn build
```

The build files will be in the `dist` directory.

## Deployment

The project is ready to be deployed to any static site hosting service like Vercel or Netlify.
